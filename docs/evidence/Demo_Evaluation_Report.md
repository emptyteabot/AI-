## 工作流

固定任务与参考要点 → 冻结数据集/模型/参数 → 队列调用（并发3、超时45s、对网络/限流/5xx最多2次尝试）→ 记录原始回答/usage/响应 ID → 规则机评 → 可选跨厂商模型裁判 → A/B匿名盲评 → 汇总分歧与报告 → 人工修订Benchmark并新建实验。
