# 验证记录

日期：2026-10-28。验收环境为 Linux / Node.js 24，本项目未含实际厂商密钥。

## 已完成

- `npm test`：14 项核心测试通过，覆盖 24 题均衡、输出约束、错误 JSON、演示数据可复现、API URL 白名单、费用未知、厂商参数、401/截断、盲评字段隔离和报告统计。
- 类型检查与生产构建：项目发布构建流程中执行，最终结果以发布记录为准。
- 浏览器：创建独立演示实验，24 题 × 3 通道共 72 条执行完毕、72 成功、0 失败；39 条命中待人工复核条件。关闭并恢复预览后，实验及结果仍存在。
- 人工盲评：在独立浏览器验收实验中提交 1 组 A/B 平局和必填理由，页面显示已评 01，随后分配下一组。该投票仅检验提交流程，不是教师质量评价，不纳入内置基线报告。
- 演示报告：`npm run demo:report` 根据同一评分代码生成原始 JSON、CSV 和 Markdown；其中不含真实模型调用、延迟、Token、费用或专家投票。

## 未完成与边界

- 截至本节记录日期，尚未实际调用三家模型或模型裁判；之后的实测见文末更新。
- 已提供 `tests/integration.mjs`，但当前验收环境的命令行与浏览器预览处于不同网络，无法通过本机命令访问预览服务，因此 HTTP 集成脚本未执行，不能宣称通过。
- 未进行 Windows/macOS 安装、移动设备或多评审员权限隔离的实机验收；本 Demo 也不具备企业级权限和身份认证。
- 在线部署环境的数据与本地预览数据库彼此独立。参考要点尚未经学科专家系统标定，演示样例分数不能解释成模型优劣。
