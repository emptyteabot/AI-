自动规则机评

选择任务并粘贴待检查的模型 JSON，立即执行确定性规则；不产生 API 费用。

规则主要判断字段、数量、时长和关键词是否出现，不证明科学性或教育安全；零剧透等扩展提示以完整平台为准。完整服务支持跨模型裁判；此备用站为静态版，不提供在线模型调用。

可复核的评测工作流
任务和评分标准 → 冻结题目与参数 → 多模型生成 → 规则与模型裁判 → 匿名人工比较 → 汇总缺陷与报告。
01 定义任务
学段、学科、Query、参考要点和硬约束版本化。
02 自动机评
规则检查和跨来源模型裁判分别记录，保留错误和截断。
03 人工盲评
同题匿名 A/B、随机顺序，记录评分与判断依据。
04 解释结果
报告样本量、失败、来源和适用范围；不夸大差距。
